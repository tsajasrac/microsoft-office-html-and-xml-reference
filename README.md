# microsoft-office-html-and-xml-reference

## About 
Original files can be found on Jason Rodriguez's linked blog post[^blog] or in the src folder.

The Decompiled CHM file "Microsoft® Office HTML and XML Reference" which is no longer actively maintained, is stored in a zip file that can also be found in the SRC folder.
