# microsoft-office-html-and-xml-reference

## Usage

### Windows
If you're on windows you can view and open all of the files. To use the CHM file on windows, you can double click it. 

If the resulting CHM file is blank: right click the file > go to **Properties** > click **Unblock** > hit **OK**. Try opening it again, and it should show content this time. 

### Mac
I'm sorry, but you're probably going to have to use the decompiled files or the PDF. 


## About 
Original files can be found on Jason Rodriguez's linked [blog post](https://www.rodriguezcommaj.com/blog/dial-ed-for-mso) or in the repository's [src](src/) folder.
