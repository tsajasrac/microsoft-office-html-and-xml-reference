ActiveRow Element (Microsoft Excel)

Contains the index number of a pane's active row in a worksheet window.

Contained In

Pane, WorksheetOptions

Remarks

If this element is not specified, the default index of the active row is 1. When the data comes from a PivotList component, the ActiveRow subelement of the Pane element is required and contains the integer 2.
